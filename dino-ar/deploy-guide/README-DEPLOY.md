# راهنمای نصب و مدیریت «بازیکا» 🦖

بسته کاملاً استاتیک + یک CMS سبک PHP (بدون دیتابیس). روی هر هاست اشتراکی
(cPanel / DirectAdmin / XAMPP) کار می‌کند.

## پیش‌نیاز
- HTTPS فعال روی ساب‌دامنه (دوربین لازم نیست، ولی برای امنیت و کش استاندارد لازم است)
- PHP 7.4+ فقط برای بخش مدیریت (admin.php)؛ بخش نمایش بدون PHP هم کار می‌کند.

## نصب
1. ساب‌دامنه بسازید (مثلاً `ar.yourdomain.com`) و SSL فعال کنید.
2. زیپ را در پوشهٔ ساب‌دامنه Upload + Extract کنید.
3. ساختار ریشه: `index.html`, `admin.php`, `update.php`, `.htaccess`, `ar/`, `vendor/`, `models/`, `assets/`, `data/`
4. تست: `https://ar.yourdomain.com` → فهرست استندها → «تماشای استند زنده».

## CMS — افزودن استند ماه جدید 🗓️
1. باز کنید: `https://ar.yourdomain.com/admin.php`
2. بار اول: رمز مدیریت را تعیین کنید.
3. «＋ استند جدید» را بزنید و فرم را پر کنید:
   - عنوان و برچسب ماه
   - تصویر پس‌زمینهٔ داخل استند (جنگل/فضا/دریا…)
   - صدای راوی
   - متن دکمهٔ ℹ
   - شخصیت‌ها: نام، مدل GLB (از کتابخانهٔ models یا آپلود مدل جدید)، عکس پاپ‌آپ، صدا، متن‌های اطلاعات، اندازه و مکان داخل استند
4. «ذخیره» → استند فوراً در صفحهٔ اصلی با QR اختصاصی منتشر می‌شود.

نکته: شخصیت‌ها **داخل قاب استند** راه می‌روند؛ محدودهٔ حرکت از فرم قابل تنظیم است.

## به‌روزرسانی خودکار 🔄
- بار اول `update.php` را باز کنید → کلید مخفی ساخته می‌شود.
- بعد از هر انتشار ما: `update.php?key=کلید` → نصب خودکار (پوشهٔ `data/` یعنی استندها و رسانه‌های شما هرگز بازنویسی نمی‌شود).
- بررسی: `update.php?key=کلید&check=1`
- cron روزانه (اختیاری): `0 4 * * * php /home/USER/public_html/ar/update.php YOURKEY`

## عیب‌یابی
- صفحهٔ نمایش سیاه + نوار خطا: متن نوار را بخوانید (مسیر فایل/اجرای اسکریپت).
- F12 → Console سریع‌ترین تشخیص است.
