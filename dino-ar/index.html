طرح تست استند 🖨️

این تصویر همان «هدف اسکن» است (طرح خودتان)؛ چاپش کنید و AR را تست کنید.

دانلود طرح

استند خودِ من 🎨

اگر طرح چاپی خودتان را دارید، کافی است همان تصویر به‌عنوان «هدف اسکن» کامپایل شود:

cd dino-ar/tools && npm install && node compile.mjs my-stand.png ../assets/targets.mind

خروجی بدون اینترنت و بدون سرویس خارجی ساخته می‌شود. تصویر باید پر از جزئیات و پرجزئیات باشد (نواحی تک‌رنگ بزرگ مثل کاغذ سفید برای اسکن مناسب نیستند).

بدون نیاز به اپلیکیشن کار در مرورگر گوشی مدل‌های سه‌بعدی CC0 صدای ساخته‌شده با سنتز
مدل‌های سه‌بعدی: Quaternius (CC0) • موتور AR: MindAR + A-Frame
برای بهترین تجربه، صفحه را روی گوشی و با اینترنت باز کنید.
