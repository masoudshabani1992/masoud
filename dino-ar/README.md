# 🦖 استند دایناسوری — واقعیت افزوده (WebAR)

محصول: **استند عکس** که با اسکن توسط دوربین گوشی، دایناسورها از روی طرح جدا می‌شوند،
در محیط واقعی راه می‌روند، تکان می‌خورند و **غرش می‌کنند**. بدون نیاز به نصب اپلیکیشن —
همه‌چیز در مرورگر گوشی اجرا می‌شود (MindAR + A-Frame).

## اجرا / پیش‌نمایش

```bash
cd dino-ar
node server.mjs          # پیش‌نمایش روی پورت 8000
```

یا هر استاتیک‌سرور دیگر (مثلاً `npx serve .`). برای کارکرد دوربین، صفحه باید با **HTTPS**
باز شود؛ روی هاست واقعی یا پیش‌نمایش Arena این‌طور است.

## اپلیکیشن اندروید 🤖

خروجی آماده: `android/out/dino-stand.apk` (حدود ۸ مگابایت، بدون Gradle ساخته شده).
تمام تجربهٔ وب به‌صورت **آفلاین** داخل APK بسته‌بندی شده؛ WebView دوربین را برای MindAR باز می‌کند.

نصب: فایل APK را روی گوشی کپی/دانلود کنید و با فعال‌گزینهٔ «نصب از منابع ناشناس» نصب کنید
(اندروید ۵ به بالا).

ساخت دوباره (اگر ابزار دارید):

```bash
cd dino-ar/android
npm install
ANDROID_JAR=/path/to/android.jar ./build.sh
```

## ساختار

| مسیر | توضیح |
| --- | --- |
| `index.html` | صفحهٔ فرود فارسی + QR برای بازکردن روی گوشی + طرح تست برای چاپ |
| `ar/` | تجربهٔ AR: اسکن استند، بیرون‌پریدن ۶ دایناسور، راه‌رفتن، غرش |
| `assets/targets.mind` | هدف اسکن کامپایل‌شده (MindAR) |
| `assets/target.png` | تصویر هدف فعلی (دهان دایناسور = جای عکس مشتری) |
| `models/*.glb` | شش دایناسور ریگ‌شده با انیمیشن Walk/Run/Idle/Attack (Quaternius، CC0) |
| `sounds/*.wav` | غرش‌های ساخته‌شده با سنتز رویه‌ای (`tools/make-roars.mjs`) |
| `vendor/` | A‑Frame 1.5، MindAR 1.2.5 و کتابخانهٔ QR — آفلاین و بدون CDN |
| `tools/` | کامپایلر هدف اسکن در Node (بدون canvas نیتیو) |
| `android/` | پروژهٔ اپ اندروید (WebView آفلاین) + APK آماده در `android/out/` |

## استفاده با طرح استند خودتان

تصویر چاپی استند باید پر از جزئیات و پرتضاد باشد (نواحی تک‌رنگ بزرگ مثل کاغذ سفید
برای اسکن ضعیف‌اند). سپس:

```bash
cd dino-ar/tools
npm install
node compile.mjs ../assets/my-stand.png ../assets/targets.mind
```

کامپایلر کاملاً لوکال است (TensorFlow.js روی CPU) و چند ثانیه تا یک دقیقه طول می‌کشد.

## دکمه‌های داخل تجربهٔ AR

- 🔊 قطع/وصل صدا
- ➖ ➕ اندازهٔ دایناسورها
- 🧭 چرخش ۹۰ درجه‌ای جهت ایستادن دایناسورها (اگر مدل‌ها برعکس راه رفتند)

## نکات فنی

- دایناسورها روی یک «زمین مجازی» که از استند به سمت بیننده بیرون زده قدم می‌زنند؛
  یعنی از هر زاویه‌ای که استند دیده شود، درست روی زمینِ صحنه می‌ایستند.
- جهت حرکت هر مدل از روی جهت سر/دم مش‌ها تنظیم شده (`yaw` در `ar/app.js`).
- مدل‌ها از FBX به GLB با `FBX2glTF` تبدیل شده‌اند تا انیمیشن‌ها حفظ شوند.
