# محتوای استند «دایناسورها» — ماه اول 🦖

این پوشه محل قرار گرفتن فایل‌های محتوایی استند دایناسورهاست.
موتور واقعیت افزوده (پوشهٔ `dino-ar`) به‌صورت خودکار از همین فایل‌ها استفاده می‌کند.

## چه فایل‌هایی اینجا آپلود شود؟

| فایل | توضیح | وضعیت |
|---|---|---|
| `images/trex.jpg` | عکس تیرکس (برای نمایش در پاپ‌آپ) | ⬜ |
| `images/triceratops.jpg` | عکس تریسراتوپس (برای پاپ‌آپ) | ⬜ |
| `images/stegosaurus.jpg` | عکس استگوزاروس (برای پاپ‌آپ) | ⬜ |
| `audio/narration.mp3` | صدای راوی (دکمهٔ پخش پایین صفحه) | ⬜ |
| `audio/roar-trex.mp3` | صدای غرش تیرکس (اختیاری) | ⬜ |
| `audio/roar-triceratops.mp3` | صدای تریسراتوپس (اختیاری) | ⬜ |
| `audio/roar-stegosaurus.mp3` | صدای استگوزاروس (اختیاری) | ⬜ |
| `docs/info.pdf` | داکیومنت اطلاعاتی محصول (اختیاری) | ⬜ |
| `info.json` | متن پاپ‌آپ هر دایناسور + متن دکمهٔ اطلاعات — **الگوی آماده در همین پوشه است؛ متن‌هایتان را جایگزین کنید** | 🟡 |
| `target.png` | اگر طرح استند عوض شده، تصویر باکیفیت آن (اگر نیازی نیست، آپلود نکنید) | ⬜ |

## روش آپلود
در صفحهٔ گیت‌هاب همین مخزن: **Add file → Upload files** و فایل‌ها را داخل
پوشهٔ `dino-ar/content/dino` (شاخهٔ `master`) بکشید و رها کنید.

## استندهای ماه‌های بعد
هر ماه یک پوشهٔ جدید مثل `content/<نام-موضوع>` ساخته می‌شود و فقط
محتوا عوض می‌شود؛ موتور بدون تغییر کار می‌کند.
