# کوشا خودرو — CMS اختصاصی

یک سامانه مدیریت محتوا (CMS) اختصاصی و مستقل (بدون وردپرس) برای وب‌سایت شرکت کوشا خودرو، نماینده رسمی فروش و خدمات پس از فروش کیا در ایران.

## تکنولوژی‌ها
- **Next.js 14** (App Router) + React 18 + TypeScript
- **Tailwind CSS** برای استایل‌دهی (تم مشکی/سفید برند کوشا خودرو)
- **GSAP + ScrollTrigger** برای انیمیشن‌های اسکرول و اسلایدر
- **Swiper** برای کارسل‌های اسلایدر، محصولات و اخبار
- **node:sqlite** (دیتابیس درون‌برنامه‌ای، بدون نیاز به سرور دیتابیس جداگانه) — بدون وابستگی به سرویس خارجی
- احراز هویت پنل مدیریت با JWT در کوکی httpOnly (کتابخانه `jose`) + هش رمز عبور با `bcryptjs`

## امکانات
### سایت عمومی
- صفحه اول با اسلایدر GSAP، کارسل محصولات، کارسل اخبار و بخشنامه‌ها، معرفی شرکت و آمار متحرک
- صفحه محصولات و صفحه اختصاصی هر خودرو (گالری، مشخصات فنی، دانلود کاتالوگ PDF)
- صفحه اخبار و بخشنامه‌ها با فیلتر نوع محتوا
- صفحه عاملیت‌ها و نمایندگی‌ها با فیلتر بر اساس شهر
- صفحه درباره ما، تماس با ما (با فرم ارسال پیام) و صفحات پویا (CMS Pages)
- سئو اختصاصی (عنوان، توضیحات، کلمات کلیدی، تصویر اشتراک‌گذاری) برای هر محصول/خبر/صفحه + sitemap.xml و robots.txt خودکار

### پنل مدیریت (`/admin`)
مدیریت کامل محصولات، اخبار و بخشنامه‌ها، عاملیت‌ها، صفحات، اسلایدر صفحه اول، پیام‌های تماس و تنظیمات سایت/سئو.

- آدرس ورود: `/admin/login`
- نام کاربری و رمز عبور پیش‌فرض از فایل `.env` خوانده می‌شود (`ADMIN_USERNAME`, `ADMIN_PASSWORD`) — **پیشنهاد می‌شود پیش از انتشار، این مقادیر را تغییر دهید.**

## راه‌اندازی
```bash
npm install
npm run dev
```
دیتابیس و داده‌های نمونه (محصولات، اخبار، عاملیت‌ها و ...) به صورت خودکار در اولین اجرا ساخته می‌شوند (`src/lib/seed.ts`).

برای ساخت نسخه نهایی:
```bash
npm run build
npm start
```

## تصاویر
تصاویر فعلی (لوگو، اسلایدر، تصاویر محصولات) به صورت نمونه و با هوش مصنوعی تولید شده‌اند و باید پیش از انتشار نهایی با تصاویر و کاتالوگ رسمی محصولات کیا و لوگوی واقعی شرکت جایگزین شوند. این کار از طریق پنل مدیریت (بارگذاری تصویر برای هر بخش) به‌سادگی قابل انجام است.
