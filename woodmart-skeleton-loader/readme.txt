اسکلت لودینگ سبک برای قالب WoodMart و صفحات فروشگاه ووکامرس.

== نصب ==
1. پوشه `woodmart-skeleton-loader` را در `wp-content/plugins/` قرار دهید.
2. افزونه را از بخش افزونه‌های وردپرس فعال کنید.
3. از مسیر «تنظیمات ← اسکلت لودینگ وودمارت» گزینه‌ها را تنظیم کنید.

== امکانات ==
* پوشش کارت‌های محصول و بخش‌های رایج WoodMart
* سازگار با بارگذاری Ajax فیلترها و صفحه‌بندی محصولات
* انیمیشن shimmer با پشتیبانی از reduced motion
* رنگ، محدوده و زمان پشتیبان قابل تنظیم
* بدون وابستگی به jQuery و با بار کم

== نکته ==
برای جلوگیری از تداخل، کش سایت و کش مرورگر را بعد از فعال‌سازی پاک کنید. اگر قالب شما کلاس متفاوتی برای کانتینر محصولات دارد، آن را در گزینه «انتخابگرها» اضافه کنید.
