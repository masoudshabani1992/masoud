# WoodMart Turbo Speed

افزونه وردپرس برای افزایش سرعت سایت‌های **WoodMart + WooCommerce**.

## نصب سریع

1. فایل `woodmart-turbo-speed.zip` را از ریشه همین مخزن دانلود کنید (یا پوشه افزونه را زیپ کنید).
2. وردپرس → **افزونه‌ها → افزودن → بارگذاری افزونه**.
3. فعال کنید.
4. از منوی **توربو وودمارت** دکمه سبز **فعال‌سازی حالت توربو** را بزنید.
5. یک صفحه را در پنجره ناشناس باز کنید و در DevTools هدر پاسخ `X-WTS-Cache: HIT` را ببینید.

## کارهایی که افزونه می‌کند

- کش تمام‌صفحه با drop-in `advanced-cache.php` (HTML قبل از بوت وردپرس)
- تأخیر جاوااسکریپت تا اولین تعامل کاربر
- تأخیر WooCommerce Cart Fragments
- حذف Photoswipe/Zoom خارج از محصول، Gutenberg، Emoji، XML-RPC
- قطع پری‌لودر و گوگل‌فونت وودمارت
- فشرده‌سازی HTML، Lazy Load، Preload تصویر LCP
- پاکسازی دیتابیس

سبد، تسویه و حساب کاربری کش نمی‌شوند.
