# راهنمای افزونه وردپرس «اپ مانوش» 🤖

اپ اندروید مانوش برای کاتالوگ، سبد و تسویه از **WooCommerce Store API** خود سایت استفاده می‌کند
(بدون نیاز به کلید). افزونه همراه (`wp-plugin/manoosh-app-auth`) فقط این ۵ کار را انجام می‌دهد:

| اندپوینت | کاربرد |
|---|---|
| `POST manoosh/v1/otp/request` | ارسال کد ۵ رقمی ورود با پیامک |
| `POST manoosh/v1/otp/verify` | تایید کد + ساخت/یافتن کاربر + صدور Application Password |
| `GET manoosh/v1/home` | بنرهای صفحه اصلی، دسته‌های ویژه، تنظیمات شگفت‌انگیز |
| `GET manoosh/v1/variations?product_id=` | تنوع‌های محصول متغیر (رنگ/وزن/...) |
| `GET manoosh/v1/orders/<id>/pay-url` | لینک پرداخت امن سفارش‌های پرداخت‌نشده |

> اگر افزونه نصب نباشد، اپ باز می‌شود و خرید مهمان کار می‌کند، اما **ورود پیامکی، بنرها و تنوع‌ها** کار نمی‌کنند.

## ۱. نصب

1. پوشه `wp-plugin/manoosh-app-auth` را زیپ کنید (داخل زیپ فقط خود پوشه باشد).
2. در پیشخوان وردپرس: **افزونه‌ها ← افزودن ← بارگذاری افزونه** ← انتخاب زیپ ← نصب و فعال‌سازی.
3. منوی جدید **«اپ مانوش»** در پیشخوان ظاهر می‌شود.

پیش‌نیازها: وردپرس ۶ به بالا + ووکامرس فعال + PHP نسخه ۷.۴ به بالا.

## ۲. تنظیم ورود پیامکی

در صفحه **اپ مانوش** سرویس پیامک خود را انتخاب کنید:

### کاوه‌نگار
- `کلید کاوه‌نگار`: API Key پنل.
- `نام قالب`: قالب Lookup که در پنل ساخته‌اید (مثلاً `verify`). متن قالب باید شامل متغیر `#token` باشد.

### فراز اس‌ام‌اس (آی‌پنل / پترن)
- نام کاربری، رمز، شماره فرستنده و **کد پترن** را وارد کنید.
- پترن در پنل باید یک متغیر با نام `verification-code` داشته باشد.

### ملی‌پیامک (پترن)
- نام کاربری، رمز و **کد متن (BodyId)** پترنی که کد را ارسال می‌کند.

### قاصدک
- `کلید قاصدک` و `نام قالب` (قالب ساده با یک پارامتر کد).

### سرویس دلخواه
- آدرس را با `{to}` و `{code}` بنویسید، مثلاً:
  `https://sms.example.com/send?to={to}&text={code}`
- متد `GET` یا `POST` و هدر اختیاری مثل `apikey: ABC123`.

### تست
شماره موبایل خود را در بخش «تست پیامک» وارد و دکمه را بزنید. اگر پیامک با کد `11111` رسید، همه‌چیز درست است ✅

> **نکته امنیتی:** کد واقعی فقط ۲ دقیقه اعتبار دارد، هر شماره ۱ دقیقه یک‌بار می‌تواند کد بگیرد و بعد از ۵ تلاش اشتباه قفل می‌شود.

### اتصال با کد خودتان (اختیاری)
اگر پنل دیگری دارید، بدون تغییر افزونه هوک بزنید:

```php
add_filter('manoosh_otp_send_sms', function ($result, $phone, $code) {
    // ارسال $code به $phone با سرویس خودتان...
    return ['ok' => true]; // یا ['ok' => false, 'error' => '...']
}, 10, 3);
```

## ۳. بنرهای صفحه اصلی

در فیلد **بنرها (JSON)** آرایه‌ای مثل نمونه زیر بگذارید:

```json
[
  {"image": "https://manooshorganic.com/wp-content/uploads/2026/07/banner1.webp",
   "title": "عسل‌های طبیعی",
   "link_type": "category",
   "link_value": "123"},
  {"image": "https://manooshorganic.com/wp-content/uploads/2026/07/banner2.webp",
   "title": "عسل خلیلو",
   "link_type": "product",
   "link_value": "33567"},
  {"image": "https://manooshorganic.com/wp-content/uploads/2026/07/banner3.webp",
   "title": "مجله مانوش",
   "link_type": "url",
   "link_value": "https://manooshorganic.com/mag/"}
]
```

- `link_type`: یکی از `product` ،`category` یا `url`.
- `link_value`: برای محصول/دسته **آی‌دی عددی**، برای لینک، آدرس کامل.
- آی‌دی دسته/محصول را از آدرس صفحه ویرایش آن در پیشخوان پیدا کنید (`post=123` / `tag_ID=123`).

سایر فیلدها:

| فیلد | توضیح |
|---|---|
| دسته‌های ویژه | آی‌دی دسته‌ها با کاما (مثلاً `12,34`) — هر کدام یک ردیف در خانه می‌شود |
| عنوان پیشنهاد شگفت‌انگیز | پیش‌فرض: پیشنهاد شگفت‌انگیز |
| مدت جشنواره (ساعت) | شمارش معکوس هر چند ساعت ریست می‌شود (پیش‌فرض ۲۴) |

## ۴. عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| اپ خطای «سرویس ورود پیامکی فعال نیست» می‌دهد | افزونه نصب/فعال نیست یا سرویس پیامک روی «غیرفعال» است |
| کد نمی‌رسد ولی «ارسال شد» می‌گوید | لاگ PHP را ببینید؛ اعتبار پنل/قالب پترن را چک کنید؛ تست پیامک را امتحان کنید |
| خطای ۴۰۴ برای `manoosh/v1/...` | پیوندهای یکتا را یک‌بار ذخیره کنید (تنظیمات ← پیوندهای یکتا ← ذخیره) |
| ورود موفق ولی سفارش‌ها خالی است | سفارش مهمان به حساب لینک نمی‌شود؛ سفارش‌های بعد از ورود نمایش داده می‌شوند |
| تنوع محصول نمایش داده نمی‌شود | محصول باید از نوع «متغیر» ووکامرس باشد |

## ۵. امنیت

- رمز اپلیکیشن (Application Password) فقط **یک‌بار** موقع تایید کد به اپ داده می‌شود و در گوشی **رمزنگاری‌شده** ذخیره می‌شود.
- با هر ورود جدید، رمزهای قبلی «Manoosh App» باطل می‌شوند.
- لینک پرداخت سفارش فقط به **مالک لاگین‌کرده همان سفارش** داده می‌شود.
