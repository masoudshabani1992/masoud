راهنمای نمایش سایت کوشا خودرو به کارفرما
=========================================

۱) فایل ZIP را در ویندوز اکسترکت کنید (راست‌کلیک → Extract All).
۲) وارد پوشه شوید و روی فایل  index.html  دوبار کلیک کنید.
۳) صفحه شروع باز می‌شود؛ با کلیک روی «صفحه اصلی» یا هر لینک دیگر، کل سایت در مرورگر نمایش داده می‌شود.
   تمام لینک‌های منوی بالا، محصولات، اخبار، بخشنامه‌ها، عاملیت‌ها و تماس با ما فعال هستند.

نکته‌های مهم
------------
• برای نمایش این نسخه به اینترنت نیاز نیست؛ همه تصاویر، فونت و فایل‌ها داخل همین پوشه است.
• این نسخه فقط برای «نمایش» است؛ فرم‌های استعلام قیمت و پنل مدیریت در آن غیرفعال‌اند.
• نسخه کامل (با فرم استعلام، پنل مدیریت و امکان ثبت محتوا) روی سرور اجرا می‌شود و
  با دستور زیر بالا می‌آید:
      npm install
      npm start
  سپس در مرورگر:  http://localhost:3000
  پنل مدیریت:      http://localhost:3000/admin
• پیشنهاد می‌شود هنگام نمایش، مرورگر را در حالت تمام‌صفحه (F11) و با بزرگ‌نمایی ۱۰۰٪ بگذارید.

-----------
تلفن رسمی: ۰۲۱-۴۹۹۷۰۰۰۰
