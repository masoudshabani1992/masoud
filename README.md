# 📦 سامانه اتوماسیون و مدیریت پروژه کارخانه جعبه‌سازی و کارتن‌سازی (پـک‌سـازان)

یک سیستم جامع اتوماسیون سازمانی (ERP & Project Automation) متناسب با استانداردهای صنعت چاپ، لامینت و جعبه‌سازی ایران با گردش کار هوشمند **۹ مرحله‌ای** و کارتابل اختصاصی برای کلیه پرسنل کارخانه.

---

## 🚀 گردش کار هوشمند ۹ مرحله‌ای (Packaging Workflow Pipeline)

1. **مرحله ۱: بازرگانی و فروش:**
   - تعریف مشتری و کارفرما
   - ثبت نوع محصول (کارتن لمینتی E/B فلوت، جعبه مقوایی ایندربرد، پشت طوسی، کرافت فست‌فود، هاردباکس)
   - ساختار باز و بست جعبه (کیبوردی، ته قفلی لاک‌باتم، دارویی، صدفی و...)
   - ابعاد دقیق (طول × عرض × ارتفاع به میلی‌متر) و تیراژ سفارش

2. **مرحله ۲: استعلام و برآورد قیمت بر اساس قیمت روز متریال:**
   - ماشین حساب صنعتی شیت‌بندی و محاسبه وزن مقوا بر اساس گرماژ و ابعاد شیت
   - محاسبه قیمت روز انواع مقوا (ایندربرد، پشت‌طوسی، کرافت و...)
   - محاسبه ورق و سینگل فلوت (E فلوت، B فلوت، C فلوت، ۳ لایه و ۵ لایه)
   - محاسبه زینک CTP و دور چاپ افست (۱ تا ۶ رنگ) یا چاپ دیجیتال و فلکسو
   - محاسبه خدمات تکمیلی (سلفون حرارتی مات/براق، یووی موضعی سیلک، طلاکوب، قالب لیزری، دایکات بوبست و جعبه‌چسبانی)
   - بهای تمام شده خام + درصد سود کارخانه و قیمت نهایی هر عدد جعبه

3. **مرحله ۳: تایید مدیرعامل:**
   - بررسی حاشیه سود و نرخ سودآوری پروژه
   - امکان اعمال تخفیف یا یادداشت‌های استراتژیک
   - تایید رسمی پیش‌فاکتور جهت ارجاع به آتلیه طراحی

4. **مرحله ۴: ارجاع به واحد طراحی و آتلیه:**
   - ترسیم خط تیغ (Dieline) با احتساب لبه چسب، خط تا و بلید
   - جانمایی فرم چاپی و تفکیک رنگ پنتون
   - آپلود فایل‌های طراحی و رندر ۳بعدی (Mockup)

5. **مرحله ۵: تایید طرح توسط مشتری:**
   - ثبت تاییدیه رسمی یا ثبت اصلاحات گرافیکی توسط مشتری / بازرگانی

6. **مرحله ۶: ساخت ماکت فیزیکی (Prototyping):**
   - برش نمونه ماکت با دستگاه کاترپلاتر
   - کنترل تلورانس ابعاد و تست جانمایی محصول داخل جعبه
   - تست استحکام خط تا و باز و بست درب جعبه
   - ثبت عکس و گزارش ماکت

7. **مرحله ۷: تایید ماکت توسط مشتری:**
   - تایید نهایی نمونه فیزیکی توسط کارفرما قبل از خرید مواد اولیه

8. **مرحله ۸: خرید متریال جعبه توسط واحد خرید و تدارکات:**
   - صدور فاکتورهای خرید شیت مقوا، رول فلوت، لنگه زینک، رنگ و چسب
   - ثبت وضعیت تخلیه در انبار مقوا و لامینت کارخانه

9. **مرحله ۹: ارجاع به خط تولید و چاپ (Production & Job Card):**
   - زمان‌بندی و پیگیری ایستگاه‌های کاری: لیتوگرافی -> چاپ افست -> سلفون‌کشی -> لامینت -> دایکات -> جعبه‌چسبانی -> کنترل کیفیت (QC) -> بسته‌بندی شیرینک -> تحویل بار

## 👥 نقش‌های کاربری و کارتابل پرسنل (Role-Based Access)

هر پرسنل با نام کاربری اختصاصی وارد کارتابل خود می‌شود و بلافاصله وظایف منتظر اقدام خود را مشاهده می‌کند:

| نام کاربری (پیش‌فرض) | رمز عبور | نام و واحد | اختیارات و دسترسی |
|---|---|---|---|
| `ceo` | `123456` | مهندس مسعود شعبانی (مدیرعامل) | تایید قیمت‌ها، سود، داشبورد آمار کلان و نظارت کلی |
| `sales` | `123456` | واحد بازرگانی و فروش | ثبت سفارش اولیه، پیگیری مشتری و تایید طرح/ماکت |
| `estimate` | `123456` | واحد برآورد و استعلام | محاسبه قیمت روز مقوا، فلوت، چاپ و خدمات |
| `designer` | `123456` | واحد طراحی و آتلیه | تهیه خط تیغ، تفکیک رنگ و آپلود موکاپ |
| `mockup` | `123456` | واحد ماکت‌سازی | برش با پلاتر و تست فیزیکی نمونه |
| `procurement` | `123456` | واحد خرید و تدارکات | خرید مقوا، زینک، ورق و تامین متریال |
| `production` | `123456` | سرپرست خط تولید | مدیریت ایستگاه‌های چاپ، لامینت، دایکات و تحویل |
| `customer` | `123456` | پرتال مشتری / کارفرما | مشاهده روند پیشرفت و ثبت تاییدیه طرح و ماکت |

> **نکته:** در نوار بالای سامانه، امکان **«تغییر سریع نقش» (Quick Role Switcher)** تعبیه شده تا بتوانید به سادگی بین کارتابل‌های مختلف پرسنل جابجا شده و تمام ابعاد سیستم را تست و ارزیابی نمایید.

## 🌐 راهنمای استقرار روی ساب‌دامین (Subdomain Deployment Guide)

برای اجرای این اسکریپت روی یک ساب‌دامین اختصاصی مانند `order.yourfactory.com` یا `panel.yourfactory.com`:

### روش ۱: استقرار روی سرور مجازی لینوکس (Ubuntu VPS) با Nginx و PM2

1. **انتقال پروژه به سرور:**
   ```bash
   git clone <repo-url> /var/www/box-factory
   cd /var/www/box-factory
   ```

2. **نصب وابستگی‌ها و بیلد فرانت‌اند:**
   ```bash
   npm run build
   ```

3. **اجرای سرویس در پس‌زمینه با PM2:**
   ```bash
   npm install -g pm2
   pm2 start server/index.js --name "box-factory"
   pm2 startup
   pm2 save
   ```

4. **کانفیگ Nginx ساب‌دامین:**
   فایل `/etc/nginx/sites-available/order` را باز کرده و محتویات فایل `deploy/nginx-subdomain.conf` را در آن قرار دهید:
   ```bash
   sudo ln -s /etc/nginx/sites-available/order /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl reload nginx
   ```

5. **فعال‌سازی SSL رایگان با Let's Encrypt:**
   ```bash
   sudo certbot --nginx -d order.yourfactory.com
   ```

---

### روش ۲: استقرار با Docker و Docker Compose

در سرور خود فقط کافی است دستور زیر را اجرا نمایید:
```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

---

### روش ۳: استقرار روی هاست اشتراکی cPanel / DirectAdmin

1. وارد سی‌پنل شده و به بخش **Setup Node.js App** بروید.
2. روی **Create Application** کلیک کنید.
3. مشخصات را به صورت زیر وارد کنید:
   - **Node.js version:** نسخه 18 یا بالاتر
   - **Application Root:** مسیر پوشه ساب‌دامین (مثلاً `order.yourfactory.com`)
   - **Application URL:** انتخاب ساب دامین مورد نظر
   - **Application startup file:** `server/index.js`
4. روی دکمه **Run NPM Install** کلیک کرده و سپس دکمه **Restart** را بزنید.
