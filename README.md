# اپلیکیشن فروشگاهی مانوش ارگانیک 🌿

اپلیکیشن موبایل فروشگاهی به سبک دیجی‌کالا برای سایت وردپرسی
[manooshorganic.com](https://manooshorganic.com/) — ساخته‌شده با **React + Vite +
TypeScript + Tailwind** و بسته‌بندی‌شده برای اندروید با **Capacitor**.

داده‌ها (محصولات، دسته‌بندی‌ها، قیمت‌ها، سبد خرید و ثبت سفارش) به‌صورت زنده از
**WooCommerce Store API** سایت شما خوانده می‌شوند.

---

## ✨ امکانات

- **صفحه خانه**: بنر اسلایدری، دسته‌بندی‌های سریع، ریل «پیشنهاد شگفت‌انگیز»،
  «جدیدترین‌ها» و «پرفروش‌ترین‌ها»
- **دسته‌بندی‌ها**: مرور همه دسته‌ها و محصولات هر دسته با مرتب‌سازی (جدیدترین،
  پرفروش، ارزان‌ترین، گران‌ترین)
- **جستجو**: جستجوی زنده در محصولات + پیشنهادهای پرطرفدار
- **صفحه محصول**: گالری تصاویر، قیمت و تخفیف، توضیحات، محصولات مشابه
- **سبد خرید**: افزودن/کم‌کردن تعداد، ذخیره‌ی محلی (localStorage)
- **تسویه حساب**: فرم گیرنده و آدرس + ثبت سفارش واقعی و انتقال به درگاه **زرین‌پال**
- **رابط کاربری فارسی و راست‌به‌چپ (RTL)** با فونت وزیرمتن
- **PWA** قابل نصب + پروژه‌ی **اندروید (APK)**

## 🚀 اجرا در حالت توسعه (وب)

```bash
npm install
npm run dev
```
سپس مرورگر را روی آدرسی که Vite نشان می‌دهد باز کنید (پیش‌فرض `http://localhost:5173`).

> نکته: داده‌ها مستقیماً از `manooshorganic.com` خوانده می‌شوند و نیاز به اتصال
> اینترنت دارند.

## 🏗️ ساخت نسخه‌ی تولید (وب / PWA)

```bash
npm run build      # خروجی در پوشه‌ی dist
npm run preview    # پیش‌نمایش نسخه‌ی build
```

## 📱 ساخت خروجی اندروید (APK)

پروژه‌ی اندروید در پوشه‌ی `android/` آماده است.

### پیش‌نیازها
- **Android Studio** (شامل Android SDK)
- **JDK 17**

### مراحل

```bash
# ۱) ساخت وب و همگام‌سازی با پروژه‌ی اندروید
npm run cap:sync

# ۲) باز کردن در Android Studio
npm run cap:open
```

در Android Studio:
- برای گرفتن **APK دیباگ**: منوی
  `Build → Build Bundle(s) / APK(s) → Build APK(s)`
  فایل خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

- برای ساخت با خط فرمان (بدون باز کردن استودیو):
  ```bash
  cd android
  ./gradlew assembleDebug
  ```

### ساخت نسخه‌ی منتشرشدنی (Release / امضاشده)
برای انتشار در گوگل‌پلی یا نصب عمومی باید APK را امضا کنید:
```bash
# ساخت keystore (یک‌بار)
keytool -genkey -v -keystore manoosh.keystore -alias manoosh \
  -keyalg RSA -keysize 2048 -validity 10000

cd android
./gradlew assembleRelease
```
سپس در `android/app/build.gradle` تنظیمات `signingConfigs` را با keystore خود
تکمیل کنید (راهنما: https://capacitorjs.com/docs/android/deploying-to-google-play).

## ⚙️ پیکربندی

| مورد | محل |
|------|-----|
| آدرس API سایت | `src/lib/api.ts` (`API_BASE`) |
| شناسه و نام اپ اندروید | `capacitor.config.ts` |
| روش پرداخت | `src/lib/checkout.ts` (`payment_method: 'WC_ZPal'`) |
| رنگ برند و فونت | `tailwind.config.js` |
| آیکون اپ | `public/icon-512.png` و `android/app/src/main/res/mipmap-*` |

### روش پرداخت
درگاه فعال روی سایت شما **زرین‌پال (`WC_ZPal`)** است. هنگام ثبت سفارش، سفارش در
ووکامرس ایجاد شده و کاربر به درگاه بانکی هدایت می‌شود. اگر درگاه دیگری اضافه کردید،
مقدار `payment_method` را در `src/lib/checkout.ts` تغییر دهید.

## 🧩 ساختار پروژه

```
src/
├── components/     # کامپوننت‌های رابط کاربری (کارت محصول، هدر، نوار پایین و…)
├── pages/          # صفحات (خانه، دسته‌بندی، محصول، سبد، تسویه و…)
├── lib/            # API، فرمت اعداد فارسی، منطق تسویه، یکپارچگی نیتیو
├── store/          # مدیریت وضعیت سبد خرید (Zustand)
├── App.tsx         # مسیرها (React Router)
└── main.tsx        # نقطه‌ی ورود
android/            # پروژه‌ی نیتیو اندروید (Capacitor)
```

## 📌 نکات فنی

- **ارز**: قیمت‌ها به تومان (`IRT`) با اعداد فارسی نمایش داده می‌شوند.
- **سبد خرید** به‌صورت محلی ذخیره می‌شود؛ هنگام تسویه با Store API همگام می‌شود.
- **CORS**: WooCommerce Store API سرصفحه‌های لازم را می‌فرستد؛ بنابراین اپ
  می‌تواند مستقیم به سایت متصل شود.
