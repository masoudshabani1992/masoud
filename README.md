# کوشا خودرو — CMS اختصاصی

سامانه مدیریت محتوای اختصاصی وب‌سایت **کوشا خودرو** (نماینده رسمی فروش و خدمات پس از فروش کیا در ایران).
جایگزین وردپرس با معماری سبک، سریع و بهینه برای سئو — بدون وابستگی به سیستم‌های خارجی.

---

## امکانات

### ۱) اخبار (`/admin/news`)
- افزودن/ویرایش خبر با ادیتور متنی (بدون وابستگی به ادیتور خارجی)
- دسته‌بندی اخبار، خبر ویژه، سنجاق‌کردن خبر مهم
- پیش‌نویس، انتشار فوری و **زمان‌بندی انتشار** (خبر در تاریخ آینده خودکار منتشر می‌شود)
- تصویر شاخص، خلاصه/لید، شمارش بازدید
- آدرس خوانا: `/news/<slug>`

### ۲) بخشنامه‌ها (`/admin/circulars`)
- شماره بخشنامه، تاریخ صدور، دسته‌بندی (فروش / خدمات پس از فروش / نمایندگی‌ها)
- نشان‌گذاری «بخشنامه مهم»
- **فایل PDF پیوست** برای دانلود
- آرشیو با جست‌وجو و فیلتر؛ آدرس اختصاصی `/circular/<slug>`

### ۳) صفحات (`/admin/pages`)
- صفحات ثابت مانند درباره ما، تماس، حریم خصوصی و قوانین
- آدرس `/p/<slug>` + قالب استاندارد / تمام‌عرض

### ۴) محصولات (`/admin/products`)
- کاتالوگ خودروهای کیا: نام، مدل، دسته (سدان/شاسی‌بلند/هیبریدی)، قیمت یا «استعلام قیمت»
- مشخصات فنی ساختاریافته (برای جدول صفحه و داده ساختاریافته گوگل)
- گالری تصاویر، وضعیت موجودی (موجود/به‌زودی/ناموجود)، محصول ویژه
- فرم **استعلام قیمت** روی صفحه محصول → ثبت در پنل `/admin/inquiries`
- ساخت خودکار داده ساختاریافته `Product` + `Offer`

### ۵) سئو (`/admin/seo`)
- برای هر خبر/بخشنامه/صفحه/محصول: عنوان سئو، توضیحات متا، کلمات کلیدی، کانونیکال، `robots`
- **پیش‌نمایش زنده نتیجه گوگل** و **تحلیل زنده سئو** (طول عنوان/توضیحات، کلمه کلیدی، لینک داخلی، تصویر، طول محتوا) با امتیاز ۰ تا ۱۰۰
- گزارش سلامت سئوی کل سایت (`/admin/seo`)
- مدیریت **ریدایرکت ۳۰۱/۳۰۲/۴۱۰** برای انتقال آدرس‌های قدیمی وردپرس
- تنظیمات: قالب عنوان، وضعیت ایندکس کلی، Google Analytics، Search Console، تصویر پیش‌فرض OG
- `sitemap.xml` و `robots.txt` خودکار + فید `feed.xml`
- داده ساختاریافته (JSON-LD): `Organization`، `WebSite`، `BreadcrumbList`، `NewsArticle`، `Product`

### ۶) سایر
- کتابخانه رسانه با کشیدن‌ورهاکردن، متن جایگزین (alt)، آپلود چندتایی
- دسته‌بندی‌ها، کاربران (مدیر کل / ویرایشگر) با رمز هش‌شده
- پشتیبان‌گیری از دیتابیس، گزارش فعالیت‌ها، داشبورد آماری
- کاملاً **راست‌به‌چپ** و فارسی، فونت وزیرمتن به‌صورت محلی (بدون CDN)
- واکنش‌گرا (موبایل/تبلت/دسکتاپ) و بدون build step

## اجرا

نیازمندی: **Node.js ۲۲.۵ یا بالاتر** (از ماژول داخلی `node:sqlite` استفاده می‌کند؛ نیازی به نصب دیتابیس یا کامپایل بومی نیست).

```bash
npm install
npm start          # http://localhost:3000
```

حالت توسعه با ری‌استارت خودکار:

```bash
npm run dev
```

### تنظیمات محیطی (اختیاری)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | `3000` | پورت اجرا |
| `DATA_DIR` | `./data` | مسیر فایل دیتابیس |
| `SITE_URL` | `http://localhost:3000` | دامنه سایت (برای canonical/sitemap) — بعد از نصب از پنل هم قابل تنظیم است |
| `ADMIN_EMAIL` | `admin@kooshakhodro.com` | ایمیل مدیر اولیه |
| `ADMIN_PASSWORD` | `Koosha@1404` | رمز مدیر اولیه |
| `SESSION_SECRET` | مقدار داخلی | کلید امضای توکن CSRF |

> ⚠️ **پس از اولین ورود، رمز عبور مدیر را از `/admin/users` تغییر دهید.**

### ورود به پنل

```
http://localhost:3000/admin
ایمیل:  admin@kooshakhodro.com
رمز:    Koosha@1404
```

## استقرار روی سرور (نمونه)

```bash
# روی سرور (Node 22+)
git clone <repo> /var/www/koosha && cd /var/www/koosha
npm ci --omit=dev
SITE_URL=https://www.kooshakhodro.com PORT=3000 NODE_ENV=production npm start
```

سرویس pm2 (یا systemd) + Nginx به‌عنوان reverse proxy:

```nginx
server {
  listen 443 ssl http2;
  server_name www.kooshakhodro.com;

  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

نکته‌ها:
- پوشه `data/` و `public/uploads/` را در بکاپ‌های دوره‌ای قرار دهید (یا از دکمه پشتیبان‌گیری پنل استفاده کنید).
- پس از تغییر دامنه، مقدار «آدرس سایت» در `/admin/settings` را به‌روز کنید تا canonical و sitemap درست تولید شوند.
- برای انتقال از وردپرس: آدرس‌های قدیمی را در `/admin/seo` به‌صورت ریدایرکت ۳۰۱ به آدرس جدید اضافه کنید.

## نکات امنیتی پیاده‌شده

- رمزها با `bcrypt` هش می‌شوند؛ نشست‌ها با کوکی `httpOnly` + `sameSite=lax`
- محافظت CSRF روی همه فرم‌های پنل و APIها
- پاک‌سازی HTML محتوا (`sanitize-html`) و محدودکردن `iframe` به دامنه‌های مجاز
- اعتبارسنجی نوع و حجم فایل در آپلود، نام‌گذاری تصادفی فایل‌ها
- پنل و API با `noindex` و `Disallow` در robots
