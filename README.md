# اپ اندروید مانوش 🤖🍯

اپلیکیشن فروشگاهی **نیتیو اندروید** برای [manooshorganic.com](https://manooshorganic.com) — با تجربه‌ای شبیه **دیجی‌کالا**، کاملاً فارسی و راست‌به‌چپ.

## امکانات

**فروشگاه کامل:**
- 🏠 خانه: بنر متحرک، دسته‌بندی‌های دایره‌ای، **پیشنهاد شگفت‌انگیز با شمارش معکوس**، جدیدترین‌ها، پرفروش‌ترین‌ها
- 🗂 دسته‌بندی دومرحله‌ای مثل دیجی‌کالا + لیست محصول با **مرتب‌سازی و فیلتر** (قیمت، موجودی، تخفیف)
- 🔍 جستجوی زنده با پیشنهاد + تاریخچه جستجو
- 📦 صفحه محصول: گالری، امتیاز، تنوع (وزن/طعم/...)، انتخاب تعداد، مشخصات، دیدگاه‌ها، کالاهای مرتبط، اشتراک‌گذاری
- 🛒 سبد خرید سمت سرور (با بستن اپ پاک نمی‌شود) + کد تخفیف
- 💳 تسویه ۳ مرحله‌ای (آدرس ← ارسال ← پرداخت) با روش‌های ارسال و پرداخت واقعی سایت + **پرداخت داخل اپ**
- 📱 **ورود با پیامک** مثل دیجی‌کالا (کاوه‌نگار / فراز / ملی‌پیامک / قاصدک)
- 👤 حساب کاربری: سفارش‌ها + جزئیات و پرداخت مجدد، علاقه‌مندی‌ها (آفلاین)، آدرس‌ها، مجله مانوش
- 🔗 باز شدن لینک‌های محصول سایت داخل اپ (App Link) + پوسته روشن/تیره + تاریخ شمسی

## معماری

```
Kotlin + Jetpack Compose (Material 3) • MVVM • Hilt • Retrofit • Room • DataStore
```

| لایه | تکنولوژی |
|---|---|
| کاتالوگ/سبد/تسویه | WooCommerce **Store API** (عمومی، بدون کلید) |
| سفارش‌ها و پروفایل | WooCommerce **wc/v3** با Application Password |
| ورود پیامکی/بنرها/تنوع‌ها | افزونه همراه `wp-plugin/manoosh-app-auth` |
| امنیت | رمز اپ در EncryptedSharedPreferences، بدون بکاپ |

## شروع سریع (۵ دقیقه)

```bash
git clone <repo> && cd <repo>
# با Android Studio باز کنید، Sync شود، دکمه Run ▶
```

یا بدون اندروید استودیو: کافی است push کنید — **گیت‌هاب خودش APK می‌سازد**
(تب Actions ← آخرین اجرا ← Artifacts ← `manoosh-debug-apk`).

> 📖 راهنمای قدم‌به‌قدم: [`docs/BUILD_AND_PUBLISH_FA.md`](docs/BUILD_AND_PUBLISH_FA.md)
> 🔌 نصب افزونه وردپرس و تنظیم پیامک: [`docs/WORDPRESS_PLUGIN_FA.md`](docs/WORDPRESS_PLUGIN_FA.md)

## ساختار ریپو

```
├── app/                    # سورس اندروید (Kotlin + Compose)
│   └── src/main/
│       ├── java/com/manoosh/app/
│       │   ├── core/       # تم، شبکه، نشست، کامپوننت‌های مشترک
│       │   ├── data/       # ریپازیتوری‌ها + Room
│       │   ├── domain/     # مدل‌ها
│       │   └── feature/    # صفحه‌ها (home, product, cart, checkout, auth, ...)
│       └── res/            # رشته‌های فارسی، آیکون، تم
├── wp-plugin/manoosh-app-auth/  # افزونه وردپرس (OTP، بنر، تنوع)
├── docs/                   # راهنماهای فارسی
└── .github/workflows/      # بیلد خودکار APK/AAB
```
