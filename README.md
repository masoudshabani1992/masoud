# WoodMart Turbo Speed

افزونه وردپرس برای افزایش شدید سرعت لود سایت‌هایی که قالب **WoodMart** و **WooCommerce** دارند.

وودمارت به‌خاطر اسکریپت‌های زیاد (اسلایدر، مگا‌منو، Quick View، Wishlist، Photoswipe، Cart Fragments و فونت گوگل) حتی روی هاست خوب کند به نظر می‌رسد. این افزونه همان گلوگاه‌ها را هدف می‌گیرد.

## نصب

1. پوشه `woodmart-turbo-speed` را زیپ کنید.
2. در وردپرس: **افزونه‌ها → افزودن → بارگذاری افزونه**.
3. فعال کنید.
4. از منوی **توربو وودمارت** دکمه **فعال‌سازی حالت توربو** را بزنید.

یا پوشه را مستقیم در `wp-content/plugins/woodmart-turbo-speed` کپی کنید.

## بعد از فعال‌سازی چه می‌شود؟

| لایه | اثر |
| --- | --- |
| کش تمام‌صفحه (`advanced-cache.php`) | HTML مهمان قبل از بوت وردپرس برمی‌گردد → TTFB خیلی پایین |
| تأخیر جاوااسکریپت | JS سنگین وودمارت تا اولین حرکت ماوس/لمس اجرا نمی‌شود → TBT و PageSpeed |
| تأخیر Cart Fragments | دیگر هر صفحه با `wc-ajax=get_refreshed_fragments` شروع نمی‌شود |
| حذف دارایی‌های اضافه | Emoji، Gutenberg، Photoswipe خارج از محصول، Select2 خارج از تسویه، فونت گوگل |
| فشرده‌سازی HTML + Lazy Load + Preload LCP | FCP/LCP بهتر |

سبد خرید، تسویه حساب و حساب کاربری **هرگز کش نمی‌شوند**.

## عیب‌یابی

- دور زدن افزونه روی یک صفحه: `?wts_disable=1`
- دور زدن کش: `?wts_nocache=1`
- اگر افزونه کش دیگری (WP Rocket، LiteSpeed Cache، FlyingPress) دارید، کش صفحه را فقط در یکی روشن بگذارید.
- WP-CLI: `wp wts turbo` ، `wp wts purge` ، `wp wts status`

## نیازمندی

وردپرس ۵.۸+ ، PHP ۷.۴+ ، و ترجیحاً PHP ۸.۱ با OPcache.
